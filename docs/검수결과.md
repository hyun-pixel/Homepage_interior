# LT인테리어 제작·검수 결과

작성일: 2026-09-27

## 제작 범위

인터뷰와 PRD에 따라 홈페이지 1차 제작을 완료했습니다. 사용자 제공 TXT는 디자인 명세로 해석해 구현했습니다.

- 주요 페이지 13개: 메인, 디자인 갤러리, LT 소개, 상담 안내, 콘셉트 상세 9개
- 별도 404 안내 페이지
- 한국 주거 공간을 표현한 AI 이미지 28장, LT 심볼 1개
- 따뜻한 스타일 4개, 모던 스타일 3개, 호텔 스타일 2개
- 샌드 베이지–아이보리 그라데이션과 월넛 브라운 강조색, 제공된 대형 영문 제목·등장 애니메이션·원본 영상 반영
- 갤러리 필터, 모바일 메뉴, 이미지 스크롤 연출
- 공간별 디자인 제안으로 소개하며 확인되지 않은 실제 시공 실적은 추가하지 않음

웹용 이미지와 작은 화면용 파일은 총 약 5.6MB입니다. 원본 생성 파일 총 약 66.7MB 대비 약 91.6% 줄였습니다. 글꼴과 아이콘은 프로젝트에 포함했습니다.

## 2026-09-27 글자 디자인 전면 점검

전체 13개 주요 페이지와 404 화면의 글자 배치·서체·크기·자간·행간을 점검하고 수정했습니다.

- 한글 본문과 설명은 Pretendard로 통일하고, 브랜드 영문은 기존 서체를 유지했습니다.
- 제목은 500 굵기, 본문은 400 굵기를 기본으로 하여 위계를 구분했습니다.
- 주요 페이지 제목은 38–84px, 상세 제목은 36–88px, 섹션 제목은 32–58px 범위에서 화면 폭에 맞춰 조절합니다.
- 긴 본문은 주로 16px, 행간 1.65–1.75배로 조정했습니다. 보조 문구는 12–15px로 정리했습니다. 로고 안의 사명 표기는 별도입니다.
- 제목의 과도한 자간 압축을 완화하고, 일반 본문 자간은 기본값으로 통일했습니다.
- 제목·본문의 불필요한 들여쓰기와 강제 줄바꿈을 줄였습니다. 사진 아래 공간 이름과 분류를 두 줄로 나눴습니다.
- 제목의 밑줄과 링크 아래의 밑줄 모양 테두리를 제거했습니다. 구역 구분선과 키보드 포커스 표시는 유지했습니다.
