# LT인테리어 홈페이지 PRD

버전 1.3 · 2026년 9월 27일 · 한국어 타이포그래피 전면 점검 및 밑줄 제거 반영

## 1. 목표

LT인테리어의 감각적인 프리미엄 이미지를 전달하는 주거 인테리어 홈페이지를 제작한다. **디자인과 화려한 연출이 최우선**이다. 제공된 「인테리어 홈페이지 레퍼런스.txt」의 디자인·배치·애니메이션·동영상을 기준으로 하며, 사진과 문구는 한국 주거 인테리어에 맞게 교체한다.

첨부 TXT는 실행 코드가 아닌 상세 제작 명세다. 원본의 부동산 브랜드명·사업 기능을 자동으로 요구사항에 포함하지 않는다. 인터뷰 결정이 우선한다.

## 5. 이미지·문구 제작안

### 5.1 9개 콘셉트 제안

이름과 소재는 확정된 4·3·2 비중을 구체화한 제작 제안이다. 실제 현장명·고객 주소·납품 자재를 주장하지 않는다.

| 번호 | 분류 | 이름 제안 | 방향 |
|---|---|---|---|
| 01 | 밝고 따뜻함 | 햇살을 담은 집 | 화이트 벽, 밝은 오크, 자연광 |
| 02 | 밝고 따뜻함 | 부드러운 여백 | 아이보리, 밝은 석재, 부드러운 곡선 |
| 03 | 밝고 따뜻함 | 포근한 일상 | 리넨 질감, 샌드 베이지, 편안한 가구 |
| 04 | 밝고 따뜻함 | 한국의 온기 | 현대 목재 격자, 여백, 자연 소재 |
| 05 | 모던 | 단정한 균형 | 회백색 석재, 정돈된 수납, 단정한 선 |
| 06 | 모던 | 고요한 대비 | 화이트·블랙, 금속 디테일, 선명한 대비 |
| 07 | 모던 | 도시의 여유 | 그레이지, 스모크 유리, 도심 주거 |
| 08 | 호텔 | 깊은 쉼 | 깊은 월넛, 크림색 패브릭, 간접조명 |
| 09 | 호텔 | 빛이 머무는 밤 | 짙은 석재, 차콜, 극적인 조명 |

- 콘셉트마다 거실·주방·침실의 재료·색·광원이 같은 집처럼 이어지도록 제작.
- 한국 주거의 공간 비례와 생활 방식 반영. 과장된 해외 대저택을 기본값으로 삼지 않음.
- 이미지 내부 텍스트·로고·워터마크 제외. 제목과 설명은 웹 문구로 처리.
- 메인 대표 이미지는 별도 1장. 소개·철학 영역은 기존 28장 중 적합한 이미지 재사용.
- **사용자 요청에 따라 홈페이지의 AI 제작 안내 문구를 모두 삭제한다. 디자인 제안이라는 소개는 유지하고, 확인되지 않은 실제 시공 실적·후기는 추가하지 않는다.**

### 5.2 브랜드 철학

중심 문장 제안: “당신의 취향으로 시작해, 오래 좋아할 공간으로.”

생활 습관과 취향을 이해하는 설계, 오래 머물러도 편안한 색과 소재, 일상에 맞는 공간 구성을 설명한다. 확인하지 않은 경력·시공 건수·만족도·수상·보증 기간을 만들지 않는다.

### 5.3 진행 과정

1. 상담: 원하는 분위기, 주거 형태, 지역, 일정 등 확인.
2. 현장 실측: 현장 상태와 공간 조건 확인.
3. 설계·견적: 생활 방식과 취향을 반영한 방향·견적 안내.
4. 계약: 범위와 일정 등 합의 내용 확인.
5. 시공: 확정된 설계와 계획에 따른 공사 진행.
6. 완공·사후관리: 마감 확인과 관리 안내. 무상 보증 기간은 별도 확인 전 명시하지 않음.

### 5.4 상담 상태

카카오톡 주 버튼 + 전화 보조 버튼. 현재 링크와 번호가 없으므로 임의 연락처를 만들지 않는다. 내부 상담 페이지는 정상 이동하며, 외부 상담은 “상담 연결 준비 중” 상태로 정확하게 표시한다. 허위 성공 안내를 띄우지 않는다.

## 6. 추가 영역 디자인

샌드 베이지·아이보리·월넛 브라운·세리프 제목·투명 버튼의 시각 언어를 연결한다. 브랜드 철학과 화보 대표 사진에만 스크롤 연동 확대 또는 잠시 고정되는 연출을 사용한다. 설명 영역은 간결한 순차 등장으로 처리한다. 페이지 전체의 스크롤을 강제로 가로채거나 스크롤바를 숨기지 않는다.

갤러리 복귀, 다른 콘셉트 보기, 상담 이동을 제공한다. 이동하지 않는 메뉴·가짜 필터를 만들지 않는다.

## 7. 기술·운영 제안

- 정적 다중 페이지 구조를 우선한다. 주요 페이지가 자체 주소로 직접 열리고 새로고침된다.
- 데이터와 공통 구성을 재사용해 9개 상세 페이지의 품질을 유지한다.
- 별도 데이터베이스·인증·런타임 유료 API가 필요 없는 구조로 제작한다.
- 이미지 크기를 명시하고 지연 로딩한다. 메인 대표 사진은 우선 로딩한다.
- 색상·글꼴·모션 시간을 공통 값으로 관리한다.
- 원본 등장 효과는 CSS·IntersectionObserver 등 기본 웹 기능을 우선 사용한다.
- 생성 이미지·로고·페이지 소스·실행 안내를 프로젝트에 함께 저장한다.
- API 키·비밀번호·접속 정보를 소스나 보고서에 포함하지 않는다.
- 유료 구매·서비스 사용, Git commit·push·PR·merge, 실제 배포를 임의 실행하지 않는다.
- 사용자 직접 Vercel 배포에 필요한 파일과 안내를 제공한다.

## 8. 반응형·접근성·예외

- 데스크톱 1440px+, 태블릿 768~1024px, 모바일 375px, 추가로 320px 콘텐츠 유실 점검.
- 860px 이하 모바일 메뉴, 기본 터치 영역 44px 이상.
- 한글 줄바꿈과 영상·이미지·버튼 겹침 방지.
- 키보드 접근, 포커스, Escape 메뉴 닫기, 현재 페이지, 이미지 대체 텍스트 제공.
- 동작 줄이기 환경에서는 과한 이동·확대를 줄이고 내용은 즉시 표시.
- 이미지 로딩으로 큰 레이아웃 이동이 생기지 않도록 크기 예약.
- 스크립트 오류로 모든 내용이 숨은 채 남지 않도록 기본 접근성 유지.
- 없는 주소에 404 안내 제공.
