# LT인테리어 홈페이지

인터뷰와 PRD를 기준으로 만든 홈페이지입니다. 운영 주소는 https://homepageinterior.vercel.app 입니다.

## 포함된 내용

- 메인, 디자인 갤러리, LT 소개, 상담 안내, 콘셉트 상세 9개: 총 13개 페이지
- 공간 이미지 28장과 LT 심볼 1개
- 밝고 따뜻한 스타일 4개, 모던 스타일 3개, 호텔 스타일 2개
- 샌드 베이지–아이보리 그라데이션·월넛 브라운 강조색, 브랜드 영문과 자연스러운 한국어 제목·등장 애니메이션·영상 카드
- 갤러리 스타일 분류, 모바일 메뉴, 화보형 상세, 핵심 사진 스크롤 연출
- PC·태블릿·모바일 대응 및 동작 줄이기 설정
- 모바일 2열 필터, 44px 이상 주요 조작 영역, 페이지별 여백·본문 간격 정돈

## 내 컴퓨터에서 보기

1. 압축 파일을 풀거나 저장소를 내려받은 뒤, **package.json**과 **미리보기.cmd**가 있는 폴더를 엽니다.
2. **미리보기.cmd**를 두 번 클릭합니다. Node.js 22 이상이 필요합니다.
3. 자동으로 열린 브라우저에서 확인합니다. 주소는 **http://127.0.0.1:4173/** 입니다.
4. 미리보기를 보는 동안 실행 창을 열어둡니다. 종료하려면 실행 창에서 Ctrl+C를 누릅니다.

HTML 파일을 직접 두 번 클릭하는 방식은 이미지의 주소가 맞지 않으므로 사용하지 않습니다. 이미 실행 중인 미리보기가 있다면 브라우저를 새로고침하면 됩니다.

명령으로 실행할 때는 프로젝트 폴더에서 다음을 사용합니다.

~~~text
npm run build
npm run preview
~~~

검증 명령은 **npm run check**입니다. 별도 데이터베이스·API 키·관리자 계정은 필요하지 않습니다.

## Vercel에 직접 배포하기

**업체 홈페이지는 상업용입니다. Vercel Hobby는 개인·비상업용으로 제한되므로 Pro 등 상업용 요금제를 확인하세요.**

- [Vercel 상업적 사용 기준](https://vercel.com/docs/limits/fair-use-guidelines)
- [Vercel 빌드 설정 안내](https://vercel.com/docs/builds/configure-a-build)

1. 사용할 GitHub 저장소는 [hyun-pixel/Homepage_interior](https://github.com/hyun-pixel/Homepage_interior)입니다.
2. Vercel 대시보드에서 **Add New → Project**를 선택하고 해당 저장소를 불러옵니다.
3. **Root Directory**는 이 프로젝트의 **package.json이 있는 폴더**로 지정합니다.
4. 아래 설정을 확인하고 본인이 **Deploy**를 실행합니다. vercel.json에도 같은 빌드 설정을 넣었습니다.

| 항목 | 설정 |
|---|---|
| Framework Preset | Other |
| Build Command | npm run build |
| Output Directory | dist |
| Node.js | 22 이상 |
| 환경변수 | 현재 구성에는 필요 없음 |

도메인 구매와 연결은 별도로 진행합니다. 처음에는 Vercel이 제공하는 주소에서 확인할 수 있습니다.

## 공개 전에 연결할 것

- 카카오톡 상담 링크와 업무용 전화번호가 아직 없습니다. 현재는 방문자에게 ‘연결 준비 중’으로 정확히 표시합니다.
- 번호와 링크를 알려주시면 제가 적용할 수 있습니다. 직접 코드를 수정할 필요는 없습니다.
- 필요한 사업자 표시 정보는 실제 정보를 확인한 후 추가합니다. 임의의 대표자·주소·등록번호·실적은 넣지 않았습니다.
- 홈페이지 사진을 바탕으로 제작한 공간 영상 4편을 프로젝트에 포함했습니다. 홈페이지 방문 시 외부 영상 서비스 연결이나 별도 API 키는 필요하지 않습니다.
- 홈페이지 문구는 로고·사명을 제외하고 한국어로 구성했습니다. 제작 방식 안내는 화면에서 제거했으며, 공간별 디자인 제안으로 소개합니다. 실제 시공 사진으로 바꿀 때는 해당 사례의 확인된 정보를 사용합니다.

## 수정할 때의 파일 위치

| 파일·폴더 | 내용 |
|---|---|
| content/site.json | 업체명·전화번호·카카오톡·영상 설정 |
| content/concepts.json | 9개 콘셉트 이름·설명·소재·색상 |
| content/image-generation-manifest.json | 이미지 목록·생성 프롬프트·크기·해시 |
| public/images | 웹에 사용하는 이미지와 작은 화면용 이미지 |
| public/videos | 거실·주방·침실·저녁 거실 영상 4편 |
| content/video-generation-manifest.json | 영상의 원본 사진·제작 정보·크기·해시 |
| public/site.css | 디자인·반응형·애니메이션 |
| public/site.js | 모바일 메뉴·필터·영상 동작 |
| scripts/build.mjs | 공통 구성을 사용해 전체 HTML 페이지 생성 |
| scripts/check.mjs | 페이지·이미지·링크·콘텐츠 구조 검사 |
| dist | npm run build로 생성하는 배포 파일. Git에는 포함하지 않음 |
| licenses | 글꼴과 Lucide 아이콘 라이선스 |
| docs | PRD·사용자 제공 레퍼런스·검수 결과 |

디자인은 제공된 레퍼런스를 우선했습니다. 브랜드 영문에는 Playfair Display·Archivo, 한글 제목과 본문·설명에는 Pretendard를 사용합니다. 제목과 링크의 밑줄을 제거하고, 화면 폭에 따라 글자 크기·줄바꿈·여백을 조절합니다. 글꼴과 아이콘은 로컬 파일로 포함되어 있습니다.

## 이미지와 영상

공간 사진은 built-in image_gen으로 제작했으며 유료 외부 API 대체 도구는 사용하지 않았습니다. 내용과 구도를 유지한 WebP 압축본, 모바일용 작은 파일을 함께 제공합니다. 원본 생성 이미지 총 66.7MB를 웹용 전체 5.6MB로 최적화했습니다.

영상은 홈페이지 사진을 바탕으로 Higgsfield에서 제작한 1080p 무음 영상 4편입니다. 거실 → 주방 → 침실 → 저녁 거실 순서로 약 20초마다 순환하며, 하단 버튼으로 서로 다른 공간을 선택합니다. 영상 파일은 H.264 MP4로 변환해 public/videos에 보관합니다. 사용자가 일시 정지하면 다른 공간을 선택해도 정지 상태를 유지하며, 운영체제의 동작 줄이기 설정에서는 자동 재생하지 않습니다. 숨겨진 탭에서는 재생을 멈추고, 다시 돌아오면 사용자가 정지하지 않은 경우에만 이어 재생합니다. 브라우저 절전·백그라운드·자동 재생 정책 때문에 모든 환경에서 영구 재생을 보장할 수는 없습니다.

## Git와 배포 상태

GitHub 저장소는 [hyun-pixel/Homepage_interior](https://github.com/hyun-pixel/Homepage_interior)이며, 기본 작업 브랜치는 main입니다. Vercel의 기존 homepageinterior 프로젝트에 배포합니다. 별도 도메인 구매와 연결은 사용자가 진행합니다. 빌드 결과물인 dist, 환경변수 파일, 설치된 의존성과 임시 로그는 Git에 포함하지 않습니다.
